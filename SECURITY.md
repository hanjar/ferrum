# Security Policy

## Reporting Security Vulnerabilities

The Ferrum team takes security issues seriously. If you discover a security vulnerability in Ferrum, please report it privately through GitHub Security Advisories rather than opening a public issue.

### How to Report

1. Navigate to the repository's **Security** tab on GitHub:
   [https://github.com/hanjar/ferrum/security](https://github.com/hanjar/ferrum/security)
2. Click **Report a vulnerability** (or go to Advisories > "New draft security advisory").
3. Provide a detailed summary including:
   - Type of vulnerability (e.g. arbitrary file write, privilege escalation, bypass).
   - Clear steps to reproduce or a minimal proof of concept.
   - Affected versions and Windows environment details.
   - Any suggested mitigations or patches.

Please do not disclose security issues publicly or send them via unencrypted personal email until they have been reviewed and addressed.

### Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |
