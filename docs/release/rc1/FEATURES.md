# Ferrum 0.1.0 RC1 — feature matrix (Stable / Beta / Unsupported)

Base: `main` @ `388e6da`. Host: Windows 11 Pro 10.0.26200, x64. Evidence and numbers: `RC-REPORT.md`.
Known problems with repro steps: `KNOWN-ISSUES.md`. Shortcuts: `SHORTCUTS.md`.

## How to read the labels

| Label           | Meaning in this RC                                                                                                                     |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| **Stable**      | Has automated tests (Rust, vitest and/or Playwright) and/or a real-exe smoke, and no open defect that changes the claim.               |
| **Beta**        | Implemented, but only partly tested, or tested only through a narrower path than the claim, or has an open known issue. Use with care. |
| **Unsupported** | Not implemented, refused by design, or blocked by licence. The app says so or the action does not exist.                               |

OS column: **Windows = tested on this host only. Linux and macOS = untested** (deferred, decision D44; no cross-OS claim is made anywhere in this RC).

Evidence caveat that applies to every row: Playwright E2E (45/45) runs the web UI in Chromium against a **mock IPC**, not the Tauri shell.
The only suite that drives the real release `ferrum.exe` in this RC is `scripts/smoke-activity.mjs` (34/34). Rust and vitest suites are real code but
do not prove the WebView2 window by themselves. AI-assistant desktop smokes need a live model provider and were **not run** in this RC.
