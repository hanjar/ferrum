# Ferrum 0.1.0 RC1 — known issues

Base `main` @ `388e6da`, Windows 11 x64. Every item has a repro and a tracking issue reference (project FER).
Severity: **High** = data loss or crash with normal use; **Medium** = wrong claim, red gate or a safety gap with a workaround; **Low** = cosmetic, docs, or an edge case.
No High issue is known. Items marked "defect" were found by this RC pass (FER-155); items marked "carried over" come from review comments in issue tracking.
