# Ferrum 0.2.2 — known issues

Platform: Windows 10/11 x64. Base `main` @ `65d7e2c`. Pre-release, unsigned installer.
Severity: **High** = data loss or crash with normal use; **Medium** = a wrong claim, a safety gap with a workaround, or a missing guarantee; **Low** = cosmetic, docs, or an edge case.
No High issue is known. Items keep their earlier IDs; KI-36 to KI-44 are new.

## F. New in 0.2.2: not manually verified before this release

The items below are covered by automated tests, but the owner did **not** test them by hand before this release. Treat them as unverified in daily use and report problems as issues.

| ID    | Sev    | Issue                                                                                                                                                                                                                                                                                         | Workaround / note                                                |
| ----- | ------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| KI-36 | Medium | The new AI actions (create 7z with a compression level, go to a path, delete to the Recycle Bin, chains of these) were tested with scripted provider replies, **not** against a real AI provider. Real models may phrase answers in ways the tests did not see.                               | Read the card before you confirm; use the file manager directly. |
| KI-37 | Medium | AI delete refuses when it cannot promise the Recycle Bin. Edge cases on volumes with a very small bin quota or with "Don't move files to the Recycle Bin" (`NukeOnDelete`) were not tried on real machines. The refusal path is tested; the exact behaviour on such volumes is not confirmed. | Delete by hand (Delete key) and pick the option you want.        |
| KI-38 | Low    | Explorer clipboard (Ctrl+C / Ctrl+X / Ctrl+V of files) was not checked by hand in full round trips: Ferrum to Explorer, Explorer to Ferrum, cut then paste, and many files at once.                                                                                                           | Use F5 / F6 or drag and drop.                                    |
| KI-39 | Low    | Opening a PDF (or any file) that is inside a **password-protected RAR** with Enter was not tried by hand.                                                                                                                                                                                     | Unpack with Alt+F9, then open the file.                          |
| KI-40 | Low    | The Menu key and Shift+F10 (context menu on the cursor row) and Ctrl+Tab / Ctrl+Shift+Tab (pane tabs) were tested in Chromium, not in the packaged WebView2 window. Windows or WebView2 may take these keys first.                                                                            | Right-click, or click the tab.                                   |
| KI-41 | Low    | The close guard (X or Alt+F4 asks while jobs run) was not tried with a hung webview. If the window cannot answer, Ferrum has an escape hatch, but its timing was not confirmed on a real hang.                                                                                                | End the task in Task Manager if Ferrum does not close.           |
| KI-42 | Low    | When a delete goes to the Recycle Bin and Windows says the item is too big for it, Windows asks whether to delete permanently. That prompt may appear **behind** the Ferrum window.                                                                                                           | Alt+Tab to find the prompt.                                      |
| KI-43 | Low    | Cancelling a **permanent** delete takes effect only between top-level items: the item being deleted (for example one huge folder) finishes first. Follow-up FER-586.                                                                                                                          | Delete large folders one at a time if you may want to stop.      |
| KI-44 | Low    | Alt access letters in dialogs and menus (underlined letters) are new and cover many dialogs; a letter may be missing or clash with a Windows or WebView2 shortcut in a dialog that was not tried by hand.                                                                                     | Use Tab and Enter.                                               |
