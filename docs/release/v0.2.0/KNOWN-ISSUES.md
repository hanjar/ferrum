# Ferrum 0.2.0 — known issues

Platform: Windows 10/11 x64. Base `main` @ `ac97ccd` plus the pending work marked in `CHANGELOG.md`.
Severity: **High** = data loss or crash with normal use; **Medium** = a wrong claim, a safety gap with a workaround, or a missing guarantee; **Low** = cosmetic, docs, or an edge case.
No High issue is known. Previous list: [`../rc1/KNOWN-ISSUES.md`](../rc1/KNOWN-ISSUES.md).

## A. Release and platform

| ID    | Sev    | Issue                                                                                                                                                                                                            | Workaround / note                                                                                            |
| ----- | ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| KI-01 | Medium | The installer and `ferrum.exe` are **not code-signed**. Windows SmartScreen warns ("Windows protected your PC") on first run.                                                                                    | Verify the SHA-256 from the release page, then More info > Run anyway. See `RELEASE-NOTES.md`.               |
| KI-02 | Low    | The installer smoke (#21) runs on a GitHub-hosted runner, which is not known to exercise the WebView2 bootstrapper download or a user-writable install folder.                                                   | Report installer problems as issues. | KI-03 | Low    | WebView2 is installed by a download bootstrapper (`downloadBootstrapper`). | KI-04 | Low    | There is no auto-updater. New versions are installed by running the new setup over the old one.                                                                                                                  | Watch the GitHub Releases page.                                                                              |
| KI-05 | Low    | Windows 10/11 x64 only. No ARM64, Linux or macOS build.                                                                                                                                                          | None.                                                                                                        |

## B. Archives

| ID    | Sev | Issue                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | Workaround / note                                                 |
| ----- | --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| KI-08 | Low | Checksum and Compare By Content of a **RAR member** are not available: UnRAR decodes a whole member to memory and cannot stream. The UI shows the reason and the backend refuses it.                                                                                                                                                                                                                                                                                                   | Unpack with Alt+F9, then checksum or compare the file.            |
| KI-09 | Low | RAR creation needs your own WinRAR 7.00 or newer (`Rar.exe`). Ferrum does not ship it and cannot create the old RAR4 format. Without a validated `Rar.exe`, RAR is not offered in the Pack dialog.                                                                                                                                                                                                                                                                                     | Pack to ZIP or 7z.                                                |
| KI-10 | Low | RAR tests build their fixtures with the tester's own `Rar.exe` and skip when it is missing, so CI does not exercise them. RAR rows in `FEATURES.md` are Beta for that reason.                                                                                                                                                                                                                                                                                                          | Run `cargo test --test archive_rar` on a machine with WinRAR.     |
| KI-11 | Low | 7z limits: compare and member reads are refused when a solid block or codec dictionary needs more than 256 MiB ("solid block/codec memory too large"). Reading one member of a big solid block still decodes the members before it, within a 256 MiB / 5 s budget. Quick View and compare decode on one thread.                                                                                                                                                                        | Prefer non-solid 7z or ZIP for large sets, or unpack with Alt+F9. |
| KI-12 | Low | Cancelling Quick View of a RAR member only stops at member boundaries; a single UnRAR `skip()`/`read()` cannot be interrupted.                                                                                                                                                                                                                                                                                                                                                         | Bounded by the size and time budget.                              |
| KI-13 | Low | Deferred review items, all safe failures: a very repetitive ZIP member of 64 KiB or more with ratio above 200x is refused for preview; a real disk folder named like `x.zip` is treated as an archive by Quick View; one invalid sibling name or one encrypted RAR member makes the whole RAR listing fail; ZIP member names with backslashes are not found; `archive_read` of a 7z with a wrong password reports a corrupt archive instead of a bad password.                         | Unpack the archive instead.                                       |
| KI-14 | Low | Extraction publishes into a destination root that is opened without following links and identity-checked (#19), but links in the **ancestors** of the root path are still resolved by the operating system.                                                                                                                                                                                                                                                                            | Extract into a directory only you can write.                      |
| KI-15 | Low | Not reproduced in this release (carried over): navigating up out of an archive with the `..` row was once reported to show an error toast.                                                                                                                                                                                                                                                                                                                                             | Use Backspace or the breadcrumb.                                  |
| KI-27 | Low | Behaviour change: file operations that change anything on an administrative share (`\\server\C$`, `ADMIN$`, drives mapped to them) or on a UNC path that points to this computer are refused (browse and read still work). Ferrum's own config, data and Activity folders cannot be a target of file operations.                                                                                                                                                                       | Use Explorer for such targets, or a normal share.                 |
| KI-28 | Low | `Rar.exe` must sit in a folder that other accounts cannot write to (for example `C:\Program Files\WinRAR`), and not on a network drive; otherwise Ferrum refuses it. Selection files are saved only as `.json` or `.ferrum-selection`.                                                                                                                                                                                                                                                 | Install WinRAR in Program Files.                                  |
| KI-29 | Low | Residual risks left open by the P3 hardening (#24): a selection file saved as `.json` can be renamed to `.bat` in a second step; an inherit-only ACE on the WinRAR folder is not evaluated; a junction inside the `Rar.exe` path is not rejected; existing entries named like a device (`nul`, `con.txt`) can still be deleted or renamed through their `\\?\` form; copy or move of a source named like a device can read the device; Recycle Bin delete of such entries is untested. | None needed in normal use.                                        |
| KI-16 | Low | Moving a file loses its comment: comments live in a per-folder sidecar (`.ferrum\comments.json`). Rename migrates the comment, move does not.                                                                                                                                                                                                                                                                                                                                          | Documented limitation.                                            |
