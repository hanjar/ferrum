# Ferrum 0.2.0 — feature matrix (Stable / Beta / Unsupported)

Base: `main` @ `ac97ccd` plus the pending work marked in `CHANGELOG.md`. Platform: Windows 10/11 x64.
Previous matrix: [`../rc1/FEATURES.md`](../rc1/FEATURES.md). Known problems: `KNOWN-ISSUES.md`. Shortcuts: `SHORTCUTS.md`.

## How to read the labels

| Label           | Meaning                                                                                                                                                             |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Stable**      | Has automated tests (Rust, vitest and/or Playwright) or a real-executable smoke script, and no open defect that changes the claim.                                  |
| **Beta**        | Implemented, but only partly tested, tested through a narrower path than the claim, depends on something outside Ferrum, or has an open known issue. Use with care. |
| **Unsupported** | Not implemented, refused by design, blocked by licence, or present in code but not reachable from the UI.                                                           |

Evidence caveats that apply to the whole matrix:

- Windows only. Linux and macOS are not built or tested, and no claim is made about them.
- Playwright end-to-end tests run the web UI in Chromium against a mock IPC, not the Tauri shell. In CI that job is optional (`continue-on-error`). The scripts in `scripts/smoke-*.mjs` drive a real `ferrum.exe` but are run by hand.
- Test counts are deliberately not repeated here: they change with every pull request. The CI "Windows Gate" job (prettier, eslint, svelte-check, vitest, build, `cargo fmt`, clippy, `cargo test --workspace`, indexer crate) is the current source.
- RAR tests build their fixtures with the tester's own `Rar.exe` and are skipped when it is missing. CI runners have no WinRAR, so RAR rows are verified locally only.
- AI-assistant desktop smokes need a live model provider and are not part of CI.
