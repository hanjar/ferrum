# Ferrum perf baseline 2026-10-06

Baseline for FER-446 (startup, memory, idle CPU). Release exe built from `main @ 7092bea` plus the measurement script
(`npm run tauri build -- --no-bundle`). Single machine, one session, other developer sessions active on the host, so
treat the numbers as an order-of-magnitude baseline, not a pass/fail threshold.

## How to run

```powershell
npm run tauri build -- --no-bundle
node scripts/measure-app.mjs src-tauri/target/release/ferrum.exe --md docs/perf/baseline-<date>.md
# options: --runs 10  --files 10000  --idle-ms 10000  --cpu-ms 30000  --json out.json  --force
```

The script refuses to run while another `smoke-*.mjs` is active (they share the real `config.json`). It backs up and
restores `config.json` byte-for-byte and removes its temp folders. Needs Windows PowerShell and WebView2 only.

## Definitions

- **Startup**: `spawn()` to first pane having at least one file row and no `aria-busy` element, via CDP polling
  (about 50 ms resolution). Each run is a fresh process; the saved tab session is dropped so every run opens the home folder.
- **Memory**: sum over the ferrum.exe process tree (ferrum.exe + msedgewebview2 children). Working set double-counts pages
  shared between WebView2 processes; private bytes does not. "Idle" = 10 s after UI ready. "10k folder" = 5 s after a
  folder with 10,000 empty-ish files finished listing. Rendered DOM rows are virtualized and depend on window size.
- **CPU idle**: CPU time of the tree over 30 s starting 10 s after UI ready, as a percent of one logical core.

## Observations

- Run 1 (about 7 s) is the first launch with a brand-new isolated WebView2 profile (profile creation); runs 2-10 reuse that
  profile and are the representative cold-process figure (about 0.9-1.5 s). The p95 of 10 runs equals the maximum, so it is
  dominated by that first run. Report both numbers when comparing.
- 10k files adds roughly 260 MB working set / 225 MB private over idle; the listing took about 0.5 s.
- Idle CPU is near zero (0.39% of one core, 0.02% of the machine).
